# Security and private data

Vernier stores sensitive local history when conversation capture is enabled. Credential redaction is best effort; the database is not encrypted. See [privacy boundaries](Docs/PRIVACY.md).

Please use this repository's **Security → Report a vulnerability** for consent bypasses, unintended data disclosure, unsafe process requests or other security issues. If that option is unavailable, open a public issue asking for a private reporting channel without including the vulnerability details or private material.

A useful private report describes affected revision/OS, expected boundary, synthetic reproduction and impact. Never send live provider credentials, a conversation archive or another person's data. There is no guaranteed response SLA or supported production release yet.
