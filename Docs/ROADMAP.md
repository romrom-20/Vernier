# Roadmap

This is a direction, not a release schedule. Contribution proposals should identify observable evidence and a user benefit before adding a metric.

## Implemented foundation

- [x] Native menu bar, Studio and optional nonactivating floating pill.
- [x] Stable hover, in-place play/pause, dragging and a native context menu.
- [x] Read-only Codex history scoped to local Conductor workspaces.
- [x] Separate metadata/content consent and in-flight revocation gate.
- [x] SQLite migrations, incremental backfill, retention, search, export and deletion.
- [x] Explicit source coverage, readable session labels and personal reflection.
- [x] Isolated synthetic showcase, shared core tests and native interaction checks.

## Next: prove the review is useful

- [ ] Test evidence-linked session reviews with consenting users before introducing a score.
- [ ] Link intent, decision, correction, artifact and follow-up across sessions.
- [ ] Represent agent claims, human reports and execution evidence separately.
- [ ] Give users a way to correct attribution and mark unresolved decisions.
- [ ] Compare the review with a human reconstruction; document false positives and missing evidence.

## Coverage and reliability

- [ ] Configurable workspace roots and richer user-chosen project labels.
- [ ] Claude Code and additional source adapters, each with a documented consent/capability contract.
- [ ] Per-session exclusions and more explicit historical import controls.
- [ ] Manual VoiceOver, keyboard navigation, crowded menu bars, multiple displays and full-screen testing.
- [ ] Actual sleep/wake/login tests and sustained energy/performance measurements.
- [ ] Developer ID signing, notarization, clean-Mac installation and an updater.

## Research only

Optional independent explanation or capability exercises could provide useful context if user-initiated and tested for validity. They are not implemented. Passive mouse/tab observation, if ever proposed, requires a separate consent design and cannot establish understanding by itself.

Strain/readiness scores, medical or cognitive-decline claims, employee monitoring and hidden screen capture are outside the current roadmap.
